
# React Props, Default Properties and This Operator

## Aim
To study and implement React Props, Default Properties
and the This Operator using programming examples.

## Introduction
React is a JavaScript library used to build user interfaces.
It uses reusable components to create applications.

## 1. React Props
Props are used to pass data from a parent component
to a child component. Props are read-only.

## 2. Default Properties
Default properties provide predefined values when
the parent component does not pass any values.

In this project, JavaScript default parameters are used
to demonstrate default properties in functional components.

## 3. This Operator
The this keyword refers to the current object or
component instance depending on the execution context.

In React class components, this.state accesses state,
this.props accesses props and this.setState() updates state.
